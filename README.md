# 🍕 Projeto Pizzaria Italiana - Geração Bela

Este projeto é um cardápio digital simples para uma pizzaria localizada em Barueri.

## 📍 Localização
* PQ-VIANA - BARUERI

## 🍕 Sabores Disponíveis
O cardápio inclui pizzas clássicas como Calabresa, Margherita, Quatro Queijos e opções doces como Chocolate.

## 🛠️ Tecnologias
* HTML5
* CSS3 (styles.css)
